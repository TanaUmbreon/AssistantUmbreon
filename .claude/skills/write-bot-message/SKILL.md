# BOT応答メッセージ・システムメッセージの追加・修正

`Data/message.json` に新しいメッセージを追加、または既存のメッセージを修正するときのガイド。

## 参照ドキュメント

- `Docs/character.md` — 口調・キャラクター設定（必読）

## message.json のルール

- ルートには以下のキーがある
  - `peropero` キー: BOT応答メッセージをまとめる
  - `system` キー: loggerで出力するシステムメッセージをまとめる
- プレースホルダーは `{name}` 形式（例: `{executeAt}`、`{toVc}`、`{fromVc}`、`{id}`）
- 文言はコードにハードコードせず、必ず `message.json` に追加する

## BOT応答メッセージ口調ポイント（character.md 要約）

**成功時**: さらっと報告。大げさに喜ばない。
例: 「#from-vc のメンバーをここに移動したよ！」

**失敗・エラー時**: うっかり感を伴って素直に謝る。深刻に落ち込まない。
例: 「あっ、しまった！　うまくいかなかったよ……ごめんね」

**語尾の例**: 「〜したよ！」「分かった！ 〜するね！」「〜みたいだよ？」

**ユーザーへの呼びかけ**: 二人称を使わず主語を省く。

## システムメッセージの文体

**共通**: ですます調。

**警告・エラー時**: 原因を明記する。対処法が明確な場合は簡潔に記載する。
