# Discord BOT 要件定義

## 概要

友人・仲間内サーバー向けの、ボイスチャンネル一斉移動BOT。

---

## 技術スタック

| 項目 | 内容 |
|------|------|
| 言語 / ランタイム | C# / .NET 10 |
| Discord ライブラリ | Discord.Net |
| 本番環境 | Docker (Ubuntu) |
| スケジューラ | インメモリ（揮発性） |

---

## 設定値管理

### 機密情報（Discord トークン等）

- **環境変数**で管理する
- 本番環境は Docker の `environment:` で注入する
- ローカル開発時は `.env` ファイルを使用し、`.gitignore` に追加して Git 管理対象外にする

### 通常設定

- **appsettings.json** で管理する
- 対象: ロール ID、ギルド ID など
- リポジトリ管理可

---

## コマンド仕様

### 共通事項

すべてのコマンドは **特定ロール保持者のみ**実行可能。

---

### `/peropero move` — ボイスチャンネル一斉移動

```
/peropero move <to:VCチャンネル> [at:yyyy-MM-dd HH:mm]
```

#### パラメータ

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `to` | 必須 | 移動先のボイスチャンネル |
| `at` | 省略可 | 実行日時（JST絶対指定）。省略時は即時実行 |

#### 動作

- 移動元 = コマンド実行者が接続しているボイスチャンネルの全メンバー
- `at` を指定した場合、指定日時にスケジュール実行される

#### エラー処理

- 実行者がボイスチャンネルに未接続の場合、コマンドを呼び出したテキストチャンネルにエラーメッセージを返す

---

### `/peropero list` — ボイスチャンネル一斉移動 予約確認

```
/peropero list
```

#### 動作

- 現在登録されているスケジュールの一覧を表示する
- 表示項目: 予約 ID・移動元VC・移動先VC・実行日時（JST）

---

### `/peropero cancel` — ボイスチャンネル一斉移動 予約キャンセル

```
/peropero cancel <id:予約ID>
```

#### パラメータ

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `id` | 必須 | キャンセルする予約の ID |

#### 動作

- 指定した予約 ID のスケジュールを削除する
- 予約者本人以外のロール保持者でも実行可能

---

## スケジュール仕様

- 日時フォーマット: `yyyy-MM-dd HH:mm`（JST 固定）
- 保存先はメモリのみ（DB なし）
- アプリ終了・BOT 再起動でスケジュールは揮発する
- 再起動後は再予約が必要（ユーザー責任）
- 実装方針: `IHostedService` + `CancellationToken` で管理
