# Discord BOT 要件定義

## 1. 概要

友人・仲間内サーバー向けの、ボイスチャンネル一斉移動 BOT。

## 2. 技術スタック

| 項目 | 内容 |
|------|------|
| 言語 / ランタイム | C# / .NET 10 |
| Discord ライブラリ | Discord.Net |
| 本番環境 | Docker (Ubuntu) |
| スケジューラ | インメモリ（揮発性） |

## 3. 設定値管理

### 3.1. 機密情報

- **環境変数**で管理する。
- 対象: Discord トークン、ロール ID、ギルド ID 等。
- 本番環境は Docker の `environment:` で注入する。
- ローカル開発時は `.env` ファイルを使用し、`.gitignore` に追加して Git 管理対象外にする。
  - 機密情報を含まない `.env.sample` ファイルを設定例として Git 管理対象にして、開発者ごとに `.env` ファイルにリネームさせ、安全に個別設定できるようにする。

### 3.2. 通常設定

- **appsettings.json**で管理する。
- 機密情報として扱わない設定全て。
- リポジトリ管理可。

## 4. コマンド仕様

### 4.1. 共通事項

- すべてのコマンドは**特定ロール（複数 ID 指定可能）保持者のみ**実行可能。
  - 実行権限を持たないメンバーがコマンド実行した場合、コマンド実行したテキストチャンネルにエラーメッセージを返す。
- 想定していないエラーが発生した場合、コマンド実行したテキストチャンネルに既定のエラーメッセージを返す。

### 4.2. `/peropero umbreon` - ブラッキーぺろぺろ

```
/peropero umbreon
```

#### パラメータ

なし

#### 動作

- コマンド実行したテキストチャンネルに固有のメッセージを返す。

#### エラー処理

コマンド固有のエラー処理なし

### 4.3. `/peropero move` — ボイスチャンネル一斉移動

```
/peropero move <to:ボイスチャンネル> [at:yyyy-MM-dd HH:mm]
```

#### パラメータ

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `to` | 必須 | 移動先のボイスチャンネル |
| `at` | 省略可 | 実行日時（JST絶対指定）。<br>`yyyy-MM-dd` は省略可能で、省略時はコマンドを実行した日。<br>全て省略時は即時実行 |

#### 動作

- ボイスチャンネルにいるメンバー全員を指定したボイスチャンネルに一斉移動する。
- 移動元は、コマンド実行したチャットを保有するボイスチャンネルを対象にする。
- `at` で実行日時を指定した場合はスケジュール予約され、その日時を経過した時に一斉移動する。
- 実行日時を省略した場合は即時に一斉移動する。
- 一斉移動が成功した場合、移動先のボイスチャンネルが保有するチャットに成功メッセージを返す。

#### エラー処理

- ボイスチャンネルが保有するチャット以外でコマンド実行した場合、コマンド実行したテキストチャンネルにエラーメッセージを返す。
- `at` が過去日時の場合、コマンド実行したテキストチャンネルにエラーメッセージを返す。
- `at` が日時フォーマットでない場合、コマンド実行したテキストチャンネルにエラーメッセージを返す。
- 移動元のボイスチャンネルにメンバーが誰もいない場合、コマンド実行したテキストチャンネルにエラーメッセージを返す。
  - 即時実行で一斉移動するタイミング、予約実行のコマンド実行したタイミング、予約日時になって一斉移動するタイミングでそれぞれ判定する。
- 他の理由でメンバー移動ができなかった場合、コマンド実行したテキストチャンネルにエラーメッセージを返す。

### 4.4. `/peropero list` — ボイスチャンネル一斉移動 予約確認

```
/peropero list
```

#### 動作

- 現在登録されているスケジュールの一覧を表示する。
- 表示項目: 予約 ID・移動元VC・移動先VC・実行日時（JST）

---

### 4.5. `/peropero cancel` — ボイスチャンネル一斉移動 予約キャンセル

```
/peropero cancel <id:予約ID>
```

#### パラメータ

| パラメータ | 必須 | 説明 |
|-----------|------|------|
| `id` | 必須 | キャンセルする予約 ID |

#### 動作

- 指定した予約 ID のスケジュールを削除する。
- 予約者本人以外でも、コマンドの実行権限があれば削除可能。

#### エラー処理

- 指定した予約 ID がスケジュールに予約されていない場合、コマンドを実行したテキストチャンネルにエラーメッセージを返す。

## 5. スケジュール仕様

- 日時フォーマット: `yyyy-MM-dd HH:mm`（JST 固定）
- 保存先はメモリのみ（DB なし）。
- アプリ終了・BOT 再起動でスケジュールは揮発する。
- 再起動後は再予約が必要（ユーザー責任）。
- 実装方針: `IHostedService` + `CancellationToken` で管理。

## 6. システム時刻仕様

- アプリを実行している端末のシステム時刻が、NTP サーバーの時刻と同期されている事を確認する。
- 参照する NTP サーバーは通常設定で指定可能（単一のサーバーを指定する）。
- NTP サーバーから時刻を取得できない場合、アプリはエラー終了する。
- NTP サーバーの時刻とシステム時刻の差が一定時間（通常設定で指定可能）離れている場合、同期されていないとみなし、アプリはエラー終了する。

### 6.1. 背景

Discord サーバー側とアプリを実行している端末側でシステム時刻に食い違いがあると、ライブラリ（Discord.Net）で例外（コマンドの 3 秒応答ルールに引っ掛かる）が発生してしまうため。
